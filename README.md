# JEV4Bili — Jev 驱动的B站刷流守门员

刷B站「看看」竖屏流时，用 [Jev](https://github.com/jev-chat/jev-chat-jarvis) 模型实时判断农场内容（营销号），弹横幅提醒你划走。

**纯无障碍方案：不 root、不破解、不调用B站任何接口、永不自动操作你的手机。**

> 灵感来自 [jev-chat/jev-chat-jarvis](https://github.com/jev-chat/jev-chat-jarvis)（BYOK 哲学）与 GKD（纯无障碍先例）。

## 它解决什么问题

B站竖屏流里混着大量以流量变现为目的的批量内容，本项目采用**宽口径**定义，以下四类全部算「营销号」：

| 类型 | 特征 | 例子 |
|---|---|---|
| 搬运缝合 | 搬运+剪辑他人素材量产，蹭流量分成 | 影视解说号、风景合集号 |
| 量产矩阵 | 一个团队N个号批量铺内容 | 短剧号、文案号、bili_XXXX默认名小号 |
| 标题党引流 | 骗点击换流量，内容与标题错配 | 「看到最后…」「99%的人不知道」 |
| 卖货导流 | 硬广软广、卖课、微信/公众号导流 | 评论区看全集、签名挂联系方式 |

目标：让 feed 只剩原创真诚内容。

## 判定分级

- 🔴 **营销号**：农场度≥阈值，建议划走（横幅停 3 秒）
- 🟡 **存疑**：农场度超线但置信不足，仅提示不打扰（2.4 秒）
- 🟢 **正常**：放行（1.8 秒）

横幅里 `味`=农场度 0~4（4=纯农场量产），`信`=模型置信度 0~1。全部判定历史可在「记录」页回看、导出。

## 快速开始（3 步）

1. 下载 Release APK 安装（允许未知来源）
2. 开启无障碍服务（设置 → 无障碍 → 已下载应用 → JEV4Bili）
3. App 设置页填**你自己的 Jev API Key**

## BYOK：你的密钥，你的额度

接口自己配——填你自己的 Jev Key，判定请求**直达 Jev 端点，不经过任何中间服务器**，作者看不到、也收不到任何内容。不填密钥 = 只做本地记录，不做 AI 判定，应用照常可用。

## 工作原理

```
B站竖屏流卡片（标题/UP主/互动数字，屏幕上公开可见的文本）
        │ Android 无障碍服务读取（含相邻卡预读：滑动瞬间预判下一条）
        ▼
   Jev API（你自己配置）→ 农场度 + 置信度
        ▼
   悬浮横幅 🔴🟡🟢 ＋ 记录页留存（本机最多300条）
```

- 判断输入只有卡片表皮可见信息，**不看、也不存任何视频内容**
- UP主画像：同一UP主的历史判定会累积成本地画像，越用越准
- 误杀防护：农场度 2.5~3.5 需高置信度才拦截，否则降级为「存疑」

## 隐私

一句话：**不收集任何数据**。零遥测、零统计、零第三方 SDK；判定请求只包含卡片文本、直达你配置的端点。全文见 [PRIVACY.md](PRIVACY.md)。

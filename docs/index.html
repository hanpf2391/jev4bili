它怎么工作

读屏上公开的文字，替你判一条「值不值得看」

四步流水线。截图与屏幕内容全程不出本机，只有卡片上那几个字会发往你自己配置的端点。

判定分级

三档结果，拦住该拦的，放过该放的

误杀比漏判更烦人，所以中间留了一档「存疑」——只提示，不打扰。

营销号 · 建议划走

农场度 ≥ 阈值，横幅停 3 秒

存疑 · 仅提示

农场度超线但置信不足，停 2.4 秒，不打扰

正常 · 放行

停 1.8 秒，不挡你滑动

横幅里 味 = 农场度 0~4（4 = 纯农场量产），信 = 模型置信度 0~1。全部判定历史可在「记录」页回看、导出。

常见问题

看之前，先看这六条

会被 B 站封号吗？

不会。不调用 B 站任何接口、不修改客户端，也不注入进程，只是读屏幕上你本来就看得见的那几个字——和你看屏幕没什么区别。

要 root 吗？要装 Xposed 吗？

都不用。纯无障碍方案，装完开一个无障碍开关就能用——不破解、不改机、不动系统，也不要任何特殊权限；关掉开关就彻底停下。

它能看到我的隐私吗？

看不到。不截图、不读视频内容，只拿卡片上那几个字；零遥测、零第三方 SDK，代码全摆在 GitHub 上，随你查。

费电吗？

约 1.8%/时，只在你刷 B 站的时候工作。主页「后台耗电」那一栏就是它自己报的数；不放心的话，把守护暂停掉就一点都不耗了。

判不准怎么办？

两个旋钮：「判定灵敏度」滑杆往右更严；单个 UP 主可加白名单／黑名单。同一 UP 主的判定会累积成本地画像，越用越准。

要花钱吗？

App 本身免费开源（GPL-3.0）。判定用的是你自己的 Jev 密钥，费用直接付给接口方，作者不经手、也看不到你的内容。
